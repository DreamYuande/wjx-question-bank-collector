# 问卷星通用题库采集

JavaScript 油猴脚本：采集当前已加载的问卷星选择题，自动去重、按问卷分别保存，并导出 Excel、CSV、JSON 或文本题库。

## 支持与暂不支持的题型

| 题型 | 支持情况 |
| --- | --- |
| 单选题 | 支持 |
| 多选题 | 支持 |
| 判断题 | 支持，通过分段标题、题型提示或明确成对选项识别 |
| 单项、多项填空题 | **暂不支持** |
| 矩阵题、矩阵量表题 | **暂不支持** |
| 简答题、量表题、排序题、文件上传等其他题型 | **暂不支持** |

适用于 `wjx.com`、`wjx.cn` 域名下 `/vm/`、`/vj/` 路径中，采用 `.field[topic][type]`、`.topichtml`、`.ui-radio` / `.ui-checkbox` 结构的页面。不是所有问卷星题型、旧版页面或自定义布局都已适配。

面板会显示“其他未支持”数量。**填空、矩阵等未支持题型不会出现在导出的题库里，也不会被计为已采集。**

## 安装与升级

1. 在浏览器中安装并启用 Tampermonkey（油猴）。
2. 打开 [wjx-question-bank-collector.user.js](./wjx-question-bank-collector.user.js)，点击 **Raw** 后按油猴提示安装；也可复制全部代码到油猴的新建脚本中保存。
3. 打开目标问卷，右下角会出现采集面板。
4. **旧版用户：先暂停采集，直接编辑原脚本，用新版代码覆盖并保存，不要先卸载。** 原脚本内升级可以保留已有存储；另外新建脚本会获得独立存储，不能直接读取旧脚本的数据。
5. 不要同时启用两份采集脚本。同一问卷只在一个标签页运行。

## 使用

1. 核对面板显示的标题、问卷编号和题型数量。
2. 填写刷新间隔，点击“开始刷新采集”；仅保存本页时点击“采集本页”。
3. 随时点击“暂停”或导出按钮。
4. “采集设置”中可填写导出类别、目标题数、无新题暂停轮数和本次轮数上限。

刷新间隔支持 `0`、`0.1`、`0.5`、`1` 等非负秒数，**没有 5 秒下限，也不额外增加随机等待**。间隔从题目加载稳定、采集并保存完成后计算；`0` 表示保存后立即刷新。网页加载与浏览器后台节流可能使实际间隔更长。

默认连续 30 轮无新题时暂停，每次开始最多 500 轮，均可调整。重新开始只重置本次轮数，不清空题库。

## Excel 导出

生成真正的 `.xlsx` 文件，包含以下六列：

| 序号 | 题型 | 类别 | 题目 | 选项 | 答案 |
| --- | --- | --- | --- | --- | --- |
| 连续编号 | 单选题／多选题／判断题 | 用户选填 | 题干文本 | 选项一&#124;选项二&#124;选项三 | 留空 |

- 按单选、多选、判断分组，组内保留首次采集顺序。
- 选项放在同一个单元格中，以 `|` 分隔，不额外添加字母编号。
- 类别默认空白，可在面板中填写。
- 页面没有提供正确答案，答案留空；不推断答案，也不把用户勾选的选项当作正确答案。
- 自动换行、冻结首行；图片仅保留网址，不下载或嵌入图片。
- 文件名包含标题、问卷编号、题数和导出时间。
- CSV 使用同样六列；JSON 保留来源题号、采集次数和原始选项，适合备份；TXT 适合阅读。

## 去重与数据保存

- 以问卷编号区分题库、采集锁、运行状态和设置，避免不同问卷混在一起。
- 按题型、题干、选项内容和图片链接去重，忽略选项排列变化。
- 完整的 `A.`、`B、` 等选项编号会移除后再匹配，原始文本保存在 JSON 的 `rawText` 中。
- 题型、题干或选项内容不同的题目会分别保存。
- 数据保存在油猴脚本存储中。卸载脚本或清除油猴数据可能删除题库，请定期导出 JSON 备份。
- 无需额外下载第三方运行库，脚本不会主动上传题库到其他服务。

## 其他限制

- 只采集当前页面已加载的受支持题目，不自动翻页、不处理登录或验证码、不填写或提交答卷。
- 按题干识别并跳过常见姓名、学工号、身份、学院等信息区，不读取或保存填写值。特殊写法仍需检查采集结果。
- 检测到用户在原答卷填写或选择时，会暂停刷新。
- 人工翻页时，先暂停、手动翻页，再点击“采集本页”。
- **连续没有新题不代表后台题库已全部采齐。** 未知题库总数时无法严格确认完整性。
- 图片链接可能失效。

已检查两个实际页面的题目结构，并用其中一个页面的结构样本验证 20 道题的提取：10 道单选、5 道多选、5 道判断，排除 2 个身份／基本信息区。另已测试题库隔离、旧数据读取、选项去前缀、乱序去重、小数秒间隔、文件名及 Excel 文件结构，并检查 Excel 显示预览。
